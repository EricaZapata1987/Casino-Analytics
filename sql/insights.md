# Preguntas de negocio e Insights

Este archivo resume algunas de las preguntas principales utilizadas para analizar el catálogo y los hallazgos más relevantes del proyecto.

## 1. ¿Qué proveedores tienen mayor presencia en el catálogo?

Los proveedores con mayor cantidad de juegos son:

- Nolimit City
- Foxium
- Playtech
- Authentic Gaming
- Tom Horn Gaming

Estos proveedores tienen presencia en los **85 casinos analizados**, lo que muestra una cobertura muy amplia dentro del catálogo.

## 2. ¿Qué tipos de juego presentan mejor RTP promedio?

Los tipos de juego con mayor RTP promedio fueron:

- Poker: 98,62%
- Table Games: 97,71%
- Live Games: 97,16%
- Crash Games: 96,97%
- Slots: 96,00%

Esto permite identificar qué tipos de juego presentan mejores niveles de retorno teórico al jugador.

## 3. ¿Cómo se comporta el RTP según la volatilidad?

El análisis mostró diferencias entre los distintos niveles de volatilidad.

La categoría **Low** presentó el RTP promedio más alto, mientras que las categorías **High** y **Very High** mostraron valores ligeramente inferiores.

Este análisis permite comparar rendimiento y nivel de riesgo dentro del catálogo.

## 4. ¿Qué funciones están disponibles en los juegos?

Se analizaron funcionalidades como:

- Mobile
- Free Spins
- Bonus Buy

La compatibilidad mobile presenta una disponibilidad muy alta, seguida por Free Spins y Bonus Buy.

Esto permite entender qué tan preparado está el catálogo para diferentes tipos de experiencia de juego.

## 5. ¿Qué juegos deberían priorizarse dentro del catálogo?

Se creó una lógica de priorización automática considerando:

- RTP
- Compatibilidad mobile
- Cantidad de países disponibles
- Multiplicador máximo

Resultado:

- **13.896 juegos — Alta Prioridad**
- **18.353 juegos — Prioridad Media**
- **331 juegos — Revisar**

Esta clasificación permite transformar distintas variables del catálogo en una herramienta simple para apoyar decisiones de negocio.

## Insight general

El análisis muestra que combinar indicadores de rendimiento, disponibilidad y características del juego permite identificar oportunidades de optimización dentro de un catálogo de gran volumen.

El objetivo final no fue solamente visualizar datos, sino convertirlos en información útil para apoyar decisiones.
